    阶段1：从零造数据库¶

    用 C 语言从字节级开始，造出一个支持 SQL、事务、崩溃恢复的迷你 RDBMS。

    学习目标¶

    通过亲手实现一个关系型数据库，理解数据库的设计哲学与底层原理：

    1. 存储层：页、Buffer Pool、B+Tree、堆表
    2. 事务层：WAL、崩溃恢复、MVCC、并发控制
    3. 查询层：SQL 解析、查询优化、执行引擎
    4. 接入层：网络协议、CLI 客户端
